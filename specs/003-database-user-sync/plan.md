# Implementation Plan: Database Schema & User Sync

**Branch**: `003-database-user-sync` | **Date**: 2026-02-08 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/003-database-user-sync/spec.md`

## Summary

Implement the complete database layer for ReelZero: install the Supabase JS client, create a SQL migration for all 6 tables (users, subscriptions, videos, generation_logs, uploaded_images, usage_tracking) plus the `reserve_credit` PostgreSQL function, define TypeScript schema types with select/insert/update variants, build typed query modules for each entity in `src/lib/db/queries/`, create a storage helper for the four Supabase Storage buckets, and wire the Clerk webhook handler to perform actual user upsert + free subscription creation. All database access is centralized through the query layer per Constitution Principle IV.

## Technical Context

**Language/Version**: TypeScript 5+ (strict mode), Next.js 16+ (App Router)
**Primary Dependencies**: `@supabase/supabase-js` (new), `svix` (existing, webhook verification), `@clerk/nextjs` (existing)
**Storage**: Supabase PostgreSQL (database) + Supabase Storage (4 buckets: videos, images, audio, thumbnails)
**Testing**: `tsc --noEmit` + `npm run lint` (build verification); manual webhook testing via Clerk dashboard
**Target Platform**: Vercel (serverless, Node.js runtime)
**Project Type**: Web application (Next.js App Router)
**Performance Goals**: Webhook processing < 5 seconds; atomic credit reservation (no race conditions)
**Constraints**: Supabase free tier (1GB storage); all DB access through `src/lib/db/queries/`
**Scale/Scope**: 6 database tables, ~12 new source files, 1 SQL migration, 1 modified webhook handler

**Structure Decision**: All new database code lives under `src/lib/db/` following Constitution Principle IV (Database Abstraction). The query layer uses one file per database table with exported named functions. The SQL migration lives in the existing `supabase/migrations/` directory. The only modification to existing code is the webhook handler at `src/app/api/auth/webhook/route.ts`, which replaces its logging placeholder with actual database operations.
