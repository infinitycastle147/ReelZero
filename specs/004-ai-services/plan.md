# Implementation Plan: AI Service Integration

**Branch**: `004-ai-services` | **Date**: 2026-02-08 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/004-ai-services/spec.md`

## Summary

Implement the AI service abstraction layer for ReelZero: script generation via Gemini 2.5 Flash (structured JSON output), scene image generation via Gemini 2.5 Flash Image (base64 PNG, resized to 1080x1920 with Sharp), text-to-speech via ElevenLabs with-timestamps endpoint (character-level timing aggregated to word-level alignment), user image uploads with validation and processing, centralized prompt templates, a generic retry utility with exponential backoff + jitter, and auto-logging of all AI operations to `generation_logs`. All AI calls go through `src/lib/ai/`, all prompts live in `src/lib/prompts/`, per Constitution Principle I.

## Technical Context

**Language/Version**: TypeScript 5+ (strict mode), Next.js 16+ (App Router)
**Primary Dependencies**: `sharp` (v0.34.5, already installed), `@supabase/supabase-js` (existing), `@clerk/nextjs` (existing)
**Storage**: Supabase Storage (`images` bucket for scene images, `audio` bucket for TTS MP3s) + Supabase PostgreSQL (`generation_logs`, `uploaded_images` tables)
**Testing**: `tsc --noEmit` + `npm run lint` + `npm run build` (build verification); manual API testing via cURL/Postman
**Target Platform**: Vercel (serverless, Node.js runtime — required for Sharp)
**Project Type**: Web application (Next.js App Router)
**Performance Goals**: Script generation < 15s, image generation < 30s per scene, audio generation < 20s, image upload processing < 5s
**Constraints**: Gemini free tier (10 RPM, 250 RPD text; 10 RPM, 100 RPD images); ElevenLabs free tier (10K chars/month); Sharp requires Node.js runtime (no Edge)
**Scale/Scope**: ~18 new source files, 4 API routes, no new database tables or migrations

No new database tables or migrations — the feature uses the existing query layer and storage helper from F003.
